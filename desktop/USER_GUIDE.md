# OPS Desktop 用户指南

> 当前仓库中的 Windows 安装候选尚未签名，也未完成生产服务与真实模型验收。正式发布前不要分发未签名候选包。

## 适用范围

OPS Desktop 是连接线上业务系统的 Windows x64 客户端。它不包含本地业务数据库或本地模型服务；你仍需登录线上账号并保持网络可用。客户端 AI 模式下，业务上下文仍经过线上 OPS 服务，再由受限通道转发到此设备上配置的模型端点。`127.0.0.1` 指运行客户端的这台电脑，并不表示提示词或业务上下文只在本机流转。

业务页面内的“模型配置”管理线上服务器模型；客户端窗口中的“本机模型配置”管理此设备使用的模型。两者互不替代。

## 启用本机 AI

### 1. 登录并打开客户端设置

先在业务窗口登录，并选定要使用的账号和工作区。从应用菜单打开“AI 连接设置…”。工作区 owner 需先在“工作区桌面 AI 策略”中允许桌面 AI；是否允许 editor 使用各自的桌面端点也由 owner 决定。

### 2. 添加兼容模型

在“本机模型配置”填写模型配置名称、API 基础地址和模型名称。地址必须是公网 HTTPS 或本机回环地址；例如本机 OpenAI 兼容服务可使用 `http://127.0.0.1:1234/v1/`。请在模型服务中启用 OpenAI 兼容接口，并填写它实际支持的模型名称。

API Key 可按服务要求填写；无鉴权的本机服务可留空。密钥只保存在当前 Windows 用户的系统加密存储中，由客户端主进程使用，不会传给业务页面或写入线上模型配置。创建本机设备或修改线上模型元数据前，客户端会要求输入当前 OPS 账号密码重新认证。

公网模型可以选择直连、系统代理或手动 HTTP(S) 代理。回环模型始终直连。系统代理、WSS 代理与模型 API 代理是不同设置；带认证的系统代理可能无法用于 WSS。客户端不支持 SOCKS、任意局域网主机、远端 DNS 代理或代理失败后自动直连。

使用图片生成且返回不同域名的图片 URL 时，在“允许的图片 CDN 域名”填写精确主机名；不支持通配符。识图与图片生成是否可用，以能力自检和任务映射为准。

### 3. 连接通道并自检能力

点击“连接 WSS 通道”。这一步只验证账号、设备和线上通道，不会调用模型。然后在“模型能力自检”中选择模型并启动自检。自检会真实调用模型，可能产生费用；它使用合成输入，不读取作品，也不执行业务工具。

只有自检通过的能力才可用于相应任务。模型支持文本，不代表它也支持 JSON、工具调用、识图或图片生成；请按自检结果配置，不要把不支持的能力映射给该模型。

### 4. 保存任务映射并应用模式

在“任务执行映射”中为每个任务选择“服务器”“此客户端”或“停用”，保存本机草稿后，再把“业务 AI 执行模式”设为“此客户端 AI”并确认应用。应用会重新加载业务页面；请先保存未提交的编辑内容。默认任务必须有有效映射；向量检索只允许服务器执行。

选择“服务器 AI”可让后续任务使用工作区的线上服务器模型。模式切换由你确认；客户端 AI 不可用时不会自动转发到服务器模型。已经开始的请求断线后也不会自动重放。

## 重连与账号管理

电脑休眠或网络中断后，客户端会断开本机 AI 通道。恢复后请从“AI 连接设置…”手动点击“连接 WSS 通道”；只有连接成功后才能继续使用已应用的此客户端模式。退出并重新打开客户端时，如果此账号仍应用了此客户端模式，客户端会尝试恢复连接；恢复失败时模式会保留并明确显示通道不可用，不会静默切换到服务器 AI。

“断开”只关闭本机 AI 通道，不会撤销线上设备；如需停用此客户端模式，请明确切换到“服务器 AI”。“清除此账号本机数据”会删除当前账号在本机保存的模型密钥、设备私钥和映射草稿，并清理当前业务站点会话后退出登录；它不会删除线上作品或撤销线上设备。设备撤销需在“本人已注册设备”中单独操作。卸载客户端可能保留 Windows 用户目录中的应用数据；多个账号需分别登录并清理。

## 故障处理

| 现象 | 处理方法 |
| --- | --- |
| 业务页面或客户端设置提示线上服务不可达 | 检查网络并重新登录；客户端不能用缓存页面代替线上业务。 |
| WSS 通道未连接或断开 | 检查线上服务状态、账号会话及代理设置，再手动连接。若账号或工作区权限已变化，请联系 owner 检查策略。 |
| 本机模型连接失败、超时或返回 401/403 | 确认本机模型服务正在运行、基础地址和模型名称正确，并检查 API Key、端口和服务日志。不要为绕过错误改用局域网地址。 |
| 能力自检未通过 | 按失败能力检查模型与兼容接口；未通过的能力不要映射到该模型。自检失败不会自动启用其他模型。 |
| 提示密钥被上游回显 | 暂停使用该模型并联系模型服务提供方；如怀疑密钥曾被外部返回，按该提供方流程轮换密钥。客户端会阻止已识别密钥进入业务响应。 |
| 需要联系支持 | 从“诊断与支持”导出脱敏诊断文件。文件不包含账号名、设备标识、模型地址、模型名称、提示词或密钥；发送前仍请自行检查文件内容。 |
