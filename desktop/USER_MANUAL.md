# OPS Desktop 功能使用手册

本文按当前桌面端界面说明各项功能怎么用。它描述已经做进客户端的操作，不代替本机 AI 连接细节（见 [USER_GUIDE.md](./USER_GUIDE.md)），也不表示安装包已签名或已完成生产验收。

OPS Desktop 是 Windows x64 客户端。业务数据在线上工作区里，客户端负责登录、创作、运营和本机能力。发行版加载桌面专用界面，并连接线上 API；未登录时不会建立本机 AI 通道。

## 1. 开始之前

### 1.1 工作区、账号和角色

先有一个工作区，再在工作区里添加平台账号。侧栏、工作台、选题、作品、日历、素材、运营、复盘和账号档案都跟着**当前平台账号**走。图片库、搜索、AI 对话和大部分设置属于当前工作区。

工作区角色：

| 角色 | 能做的事 |
| --- | --- |
| 所有者（owner） | 管理成员、平台账号、工作区策略、服务器模型和桌面 AI 策略；可以创作。 |
| 编辑者（editor） | 可以创作和修改被授权的内容。部分工作区开关和成员端点要所有者先打开。 |
| 观察者（viewer） | 只读。可以查看检查结果、作品和设置，不能起草、回填、发起平台登录或修改敏感词。 |

系统管理员代入某个工作区时，只能查看，不能改桌面 AI 策略，也不能代发平台读取。

底部状态栏显示当前工作区名和当前平台账号名。标题栏「客户端」菜单第一项显示工作区是否已登录，以及当前是「服务器 AI」还是「此客户端 AI」。

### 1.2 三个平台和内容形态

添加账号时选定平台和形态。同一平台内可以事后迁移类型；迁移后按新形态创作。

| 平台 | 可选形态 |
| --- | --- |
| 公众号 | 长图文、问答体长图文、资讯简报、图文卡片、口播脚本、漫画 |
| 小红书 | 图文笔记、清单合集笔记、图文卡片、口播脚本、漫画 |
| 今日头条 | 文章、微头条 |

公众号长图文可以配置开发者凭证，用于写入草稿箱。小红书和今日头条走发布包，由你在平台后台手动发布。头条文章和微头条在复盘里分开比较。

### 1.3 第一次打开

1. 启动客户端，在登录页使用线上账号登录。首次部署若提示初始化，按设置向导创建工作区。
2. 桌面端必须先选定一个可访问的平台账号，才会进入工作台。没有可用账号时，打开头像菜单里的账号选择器，或到「平台账号与凭证」添加。
3. 当前账号已停用、不属于本工作区或已无法访问时，主界面只显示说明，不展示其他账号的内容。从头像菜单换一个有效账号。
4. 所有者添加账号：头像菜单「添加账号」，或设置里的「平台账号与凭证」。编辑者不能替工作区创建账号。

退出前客户端会尝试保存业务页里还没提交的内容。保存失败或超时会取消退出。若当时有本机模型调用，退出会终止这些调用，且不会自动重发。

## 2. 窗口怎么走

### 2.1 标题栏

标题栏左侧是后退、前进。三个菜单：

- **客户端**：当前工作区与 AI 模式；「AI 连接设置…」打开本机设置；「重新登录…」回到登录页；关于；退出。
- **编辑**：撤销、重做、剪切、复制、粘贴、全选。
- **视图**：重新加载、强制重新加载、实际大小、放大、缩小。

### 2.2 侧栏

侧栏品牌为「OPS 灵感空间」，可折叠。分组如下：

| 分组 | 入口 |
| --- | --- |
| 创作 | 工作台、作品、选题池、内容日历 |
| 资源 | 素材库、图片库 |
| 运营 | 运营、复盘、账号档案 |

AI 对话不在这三组里，从头像菜单或命令面板进入，地址是 `/agent`。

头像菜单还可以：切换工作区、切换平台账号、打开设置、查看通知、退出登录。切换账号时，如果人还停在设置页，会留在当前设置子页，只更换记忆中的账号。

### 2.3 命令面板和随手记录

按 `Ctrl+K` 打开命令面板。可以用名称、拼音首字母搜索页面、设置、最近打开和星标。面板里也能直接记灵感或存素材。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+K` | 命令面板 / 搜索 |
| `Ctrl+Shift+I` | 记一条灵感，进入选题收件箱 |
| `Ctrl+Shift+M` | 把选中文字或粘贴内容存为素材 |
| `?` | 查看快捷键（在命令面板里也可打开） |
| `Ctrl+Shift+O` | 在 AI 对话里新建对话 |
| `Ctrl+Shift+F` | 搜索本人对话；在作品编辑器里同一组合键用于专注模式 |
| `Ctrl+Shift+B` | 收起或恢复 AI 对话列表 |
| `Ctrl+Shift+J` | 打开或收起 AI 工作视图 |
| `Ctrl+F` | 在当前对话里查找已保存消息 |

写作时另有：`Ctrl+Enter` 起草当前段或提交指令，`Ctrl+Shift+R` 改写选中文字，`Ctrl+J` 打开副驾驶，`F11` 专注模式，`Ctrl+S` 立即保存并留一个手动版本，`Ctrl+Z` 只撤销当前段落内的修改。

快速记录窗口里，如果正文含有小红书或公众号文章链接，可以勾选「读取页面为对标参考」。读取受站点 robots 和限额约束，读不到时改为手动粘贴正文。

## 3. 工作台

路径：侧栏「工作台」。

工作台是当前账号的当天入口，不代替作品编辑器。

- **继续创作**：打开最近一篇未完成作品；没有作品时从这里开始新建。
- **创作阶段入口**：按草稿、检查、待发布等阶段跳到对应列表。
- **待回填**：已写入草稿箱或已生成发布包、还没补平台链接和数据的作品。点进去补回填，供以后复盘。
- **最近打开**：本机记住的最近作品，只属于当前登录用户和当前工作区。
- **今天的主线**：把今天值得处理的小事列出来，包括到期的计划发布提醒。
- **全部作品待办**：按状态把作品分成几组，点进对应步骤。

计划发布日到期只会提醒。工作台不会在那一天自动写入草稿、推送或发布。

## 4. 选题池

路径：侧栏「选题池」。桌面是左列表、右详情。

页签：

| 页签 | 用途 |
| --- | --- |
| 待定 | 还没决定写不写的选题 |
| 已采用 | 决定要写、或已经生成作品的选题 |
| 已放弃 | 明确不做的选题 |
| 收件箱 | 随手记的灵感，尚未变成选题或素材 |
| 系列 | 把相关选题收成一组，起草时可以参考前后篇 |

待定、已采用、已放弃可以按标题搜索，并按来源筛选。

一条选题上可以：

- **采用，稍后写**：只改状态，不立刻建作品。
- **开始创作**：按这条选题新建作品并进入编辑器。已有关联作品时改为打开那篇作品。
- 放弃、恢复、置顶。
- 在详情里看角度、参考和来源。

收件箱要逐条处理：转成选题，或存成素材。没有「全部转选题」。

系列用于组织，不批量起稿。

## 5. 作品：从起草到你自己发布

路径：侧栏「作品」。

### 5.1 列表

可按状态、标签、成员筛选，也可以把当前筛选保存成视图。状态大致是：起草中、检查中、审阅中、可发布、已写入草稿、已生成发布包、已发布。

- **新建作品**：空白稿，进入编辑器。
- **导入旧文**：仅公众号长图文账号显示，用于把已有文章带进工作区。
- **去发布**：状态为可发布时，公众号去「写入草稿」，其他平台去「发布包」。
- 删除作品前会说明影响。公众号草稿箱里已经写入的草稿不会被客户端删掉。

星标后可在搜索页的星标列表里找回。

### 5.2 编辑器

作品页顶部是发布进度。按形态和平台出现这些步骤：

| 步骤 | 什么时候出现 | 做什么 |
| --- | --- | --- |
| 创作 / 卡片 / 漫画 | 始终有 | 写正文。图文卡片用卡片编辑器，漫画用漫画编辑器。 |
| 对照改写 | 作品有对照来源、且不是图文卡片 | 对照原文改写，不覆盖你没确认的段落。 |
| 排版预览 | 公众号、且不是图文卡片 | 按账号排版默认值看成文效果。 |
| 发布前检查 | 始终有 | 规则检查、敏感词和需要你确认的项。 |
| 写入草稿 / 图片草稿 | 公众号 | 写入公众号草稿箱。客户端不直接发布。 |
| 发布包 | 小红书、今日头条 | 生成你复制到平台后台的发布材料。 |

顶部还可以：改标题、打开版本历史、复制为新草稿。在创作页还能「口述 / 要点扩写」「生成标题候选」「导出 Markdown」。

左侧栏分组：

- **写作**：素材、副驾驶、待核实。
- **修改**：通读、体检。
- **协作**：批注、动态。

副驾驶只改你指定的段落或选区。待核实列出 AI 写进正文、还没被你确认的事实。素材侧栏只引用你勾选的素材，AI 不会把整个素材库默默写进稿子。

`Ctrl+S` 会立刻保存并留一个手动版本。自动保存和手动版本是两件事：退出前若保存没确认成功，退出会被取消。

封面、组图、视觉卡片在对应形态的创作面板里单独生成或上传。生成结果要你确认后才进入作品。图片汇总到工作区图片库，换一篇作品时用「从图片库选择」复用，不必重新上传。

### 5.3 发布前检查

检查由你发起。观察者只能看结果。

检查通过后作品进入可发布。若工作区要求审阅，会通知所有者，以及你指定的审阅人。审阅人不能是这篇稿子的当前执笔人。没有「全部确认」：需要人工放行的项逐条处理。

检查报告可以单独打开，用来留档或交给审阅人。报告记录最近一次检查和审阅人。

### 5.4 写入草稿和发布包

- **公众号**：在「写入草稿」里把当前稿写入草稿箱。写入前可按这篇再改评论开关等单篇选项。写完后回到同一页回填正式链接。
- **小红书 / 今日头条**：在「发布包」生成文案、图片和发布说明，由你在平台后台发布，再回到发布包页回填链接。

回填只记录你填的链接和后续数据，不会替你在平台上点击发布。待回填的作品会出现在工作台。

## 6. 内容日历

路径：侧栏「内容日历」。

把作品或选题拖到某一天，或在未排期列表里选日期，设为**计划发布日**。日历按平台和形态显示，已发布和计划中用不同标记。

计划发布日只做提醒：到期后出现在工作台「今天的主线」。到那一天，系统不会自动写入草稿、生成发布包或发布。清除计划日只去掉提醒。

未排期列表给出下一步该去创作、检查还是发布，点标题进对应步骤。

## 7. 素材库和图片库

### 7.1 素材库

路径：侧栏「素材库」。素材是事实、经历和观点的来源。AI 起草时只使用你在编辑器里选中的条目。

- **添加素材**：写正文、来源和标签。数据类素材要写出处，发布前方便核对。
- **共享素材**：勾选后当前工作区所有账号都能引用。删除某个平台账号时，共享素材会留下来，并解除和该账号的关联。
- **AI 建议类型与标签**：逐条建议。接受或跳过都针对这一条，没有「全部接受」。
- **从长文提炼**：粘贴文章、笔记或访谈，AI 只摘录原文里有的信息。你逐条决定是否存入。
- **相似素材**：按组列出。合并时保留你选的一条，其余进回收站；引用了被合并条目的作品会改指向保留的那条。
- **删除**：先说明有哪些作品引用它。删除后进回收站，正文里的引用会变成不可见。需要保留事实依据时，先改完正文再删。

`Ctrl+Shift+M` 可在任意页把选中文字存进来。

### 7.2 图片库

路径：侧栏「图片库」。这里汇总当前工作区作品里的图片，区分上传和 AI 生成。

可按描述搜索，按作品筛选。打开一张图可以看来源、尺寸、替代文字和被哪些作品使用。编辑器里的「从图片库选择」复用已有图片，不重复占用上传额度。

图片库本身不负责上传。上传和生成都在作品编辑器里完成。

## 8. 运营

路径：侧栏「运营」。页内六个页签，右侧固定显示内容节奏。

| 页签 | 用途 |
| --- | --- |
| 运营方案 | 起号问卷、定位、节奏、对标和热点开关。可看当前方案和版本历史。 |
| 内容大纲 | 按方案展开的排期槽位。采用某一条不会自动确认观点、大纲或批量起稿。 |
| 热点参考 | 账号启用热点后，查看可参考的热点。是否换成热点选题由你逐条决定。 |
| 对标参考 | 单篇链接的参考队列。小红书和公众号受 robots 限制时，在这里手动粘贴正文再提炼。每次最多添加 20 个单篇链接。 |
| 每日推荐 | 当天主推和备选。生成和采用分开。 |
| 推荐统计 | 推荐被采用和后续表现的统计。形态不同会分开算。 |

运营方案里填写领域、经历、受众、每周投入和旧作品样本后生成方案。生成结果要你启用才生效。账号类型变了之后，作品形态提示会变，需要重新生成方案。

对标账号可以写在方案里。四问评估、笔记拆解和后续编辑以账号档案的「对标库」为准，方案页上的旧对标只读，两边不要同时改。

每日推荐的生成方式可沿用工作区默认、关闭、打开时准备，或每天后台准备。后台小时、主推数量和备选数量在「每日推荐设置」里改，账号方案里也可以覆盖。

右侧「内容节奏」显示每周篇数、形态、发布日和下一篇日期，并可跳到内容日历。

## 9. 复盘

路径：侧栏「复盘」。

只列出已经写入草稿箱、已生成发布包或已发布的作品。比较用的是发布后第 7 天的数据。头条可额外看展现和点击率，文章与微头条分开筛选。

使用顺序：

1. 在发布步骤回填链接。看板会标出「待回填链接」或「已回填，未录数据」。
2. 录入阅读、收藏、分享等平台数据。没有数据的作品不能加入本次复盘。
3. 勾选已有数据的作品，发起 AI 复盘。生成在后台进行，完成后有通知。
4. 打开报告。增强复盘包含观察、可能解释、实验建议和选题建议。你可以改文字后再保存。
5. 实验建议和选题建议需要你逐条采纳，才会进入后续创作。报告不会自动改作品或批量建稿。

观察者可以看报告，不能录入或发起复盘。

## 10. 账号档案

路径：侧栏「账号档案」。每个平台账号单独一份。页首有账号健康度。

| 页签 | 用途 |
| --- | --- |
| 定位 | 定位标签、目标读者、语气、禁用词和风格摘要。可从 1–10 篇旧文生成草稿，再勾选要采用的字段。无法判断的项留空。 |
| 风格样本 | 给 AI 参照的成文样本。 |
| AI 记忆 | 最多 200 字的写作偏好。你亲手写的条目直接生效；从编辑器里提炼出来的条目要确认后才生效。可停用或删除。 |
| 账号分析 | 看这个账号的内容与数据概况。 |
| 主页自检 | 对照主页呈现做检查。 |
| 视觉 DNA | 封面和配图的视觉约束。 |
| 对标库 | 维护对标账号、四问评估和笔记拆解。 |
| 评论台账 | 记录评论，不在这里批量回复平台。 |
| 回复标准 | 规定以后回复评论时要遵守的口径。 |
| 角色卡 | 仅漫画账号。维护角色，供漫画创作引用。 |
| 排版 | 仅公众号。正文字号、行距、段间距、评论开关等，只影响之后新建的作品；推送单篇时还可以再改。 |

桌面端账号档案里没有「写作技能」页。技能库在 Web 端维护。桌面创作和 AI 对话仍使用服务端已确认的技能。

定位档案保存后，之后的 AI 生成会带上这份档案。记忆按作用范围在起草、改写、标题和选题时附带。

## 11. AI 对话

路径：头像菜单或命令面板中的「AI 对话」。

桌面对话是左列表、中对话、右工作视图。列表可搜索、按归档、状态、账号和分组筛选。

### 11.1 三种模式

输入框旁切换：

| 模式 | 行为 |
| --- | --- |
| 讨论 | 只对话，不提出写入卡片。观察者固定在这一模式。 |
| 计划 | 先给出计划，再等你确认。 |
| 执行 | 可以提出操作卡片。每张卡片单独执行，没有「全部执行」。 |

运行中或正在执行卡片时，模式锁定。

### 11.2 发消息

可以上传附件、用 `@` 引用作品 / 素材 / 选题、用 `$` 请求已确认的技能。运行中发来的补充可以进入队列：补充当前任务，或排到下一条。队列可暂停、编辑、撤回。一轮结束后，待复核的输入可以移回输入框或丢弃。

消息上可以复制、编辑、从某一条继续分出新对话。标题可直接改，最长 60 字。

若工作区允许选择模型，输入框可以选择本次使用的模型。模型不可用时，输入会说明原因（未配置、未自检、观察者、管理员代入等），不会假装已经发出。

### 11.3 工作视图

按 `Ctrl+Shift+J` 打开。页签：

- **当前任务**：运行状态、本对话操作卡片数量、任务目标、排队输入。有委派组时可以折叠、展开或停止单项协作。
- **上下文**：本对话引用了什么。
- **产物**：本对话产出的可回查结果。浏览器读过的页面证据也在来源里。
- **浏览器**：本机浏览器协作状态。工作区没开浏览器协作、扩展没连上或当前不是桌面端时，这里会写明原因，不会显示成已连接。

任务目标要单独保存：目标、完成条件、预算和账号。普通问答不会自动变成后台任务。目标可以改版本、完成或结束。

例行任务是受限的只读定时，在添加菜单里配置。它不获得批量写入权限。

添加菜单里，「Google Chrome 标签」「记忆」「插件与工具」「并行协作」「应用选择」当前标为未开放，点不开。浏览器协作请用工作视图的「浏览器」页，按页面提示加载 Chrome 扩展或使用桌面端应用内浏览。

### 11.4 操作卡片

执行模式下，助手提出的写入以卡片出现在对应消息下。你核对目标、参数和影响后，逐张执行或拒绝。执行结果写回对话。已经开始的本机模型请求如果断线，不会自动重放，也不会悄悄改走服务器模型。

个人记忆候选如果出现，也要你确认后才写入「个性化 · 记忆」。

## 14. 平台登录与同步

平台登录只在桌面端发起。服务端不代你登录，也不保存平台 Cookie 或密码。登录态留在这台电脑上。

入口：设置 → 平台账号与凭证 → 当前账号的「平台登录与同步」。按钮会打开本机登录窗口，并带到「账号与设备」。

### 14.1 登录和同步是两步

1. 所有者先打开「启用本工作区平台数据读取」。没开时，编辑者不能登录，人工回填仍然可用。
2. 公众号、小红书点「在本机扫码登录」。今日头条点「打开头条官方登录页」。目标账号固定为主窗口当前账号，登录窗里不能改选别人的账号。
3. 登录后由你本人核对稳定身份。核对通过只表示连接建立，**不会自动同步历史作品**。
4. 连接、作品列表能力、指标能力和服务端验收开关都满足后，「同步平台账号」「刷新作品指标」才会可点。缺任何一项，按钮旁会写明原因。
5. 头条在身份与数据读取能力未验证前，不提供自动同步。作品仍用发布包手动发布。

编辑者要使用自己持有的平台连接，还需要所有者允许成员建立本人连接。观察者只读。停用的账号不能登录，也不能发起新的采集。

### 14.2 连接上看什么

已连接时可以看到：平台账号标识、可用性、这台客户端是否在线、平台资料、数据读取同意版本、自动采集开关、最近验证时间和连续失败次数。

- **自动采集**：关闭后不再领取新任务；已经领走的任务按取消处理。连续失败达到 5 次会暂停自动采集。
- **自动采用**：把采集结果写入正式指标。界面上这项保持关闭，不能在这里打开。正式指标仍以你在复盘里录入或单独确认的数据为准。
- **同步进度**：排队、进行中、等待本机、等待重新登录、部分完成、失败。可以暂停、继续、取消，并查看作品同步明细和本次覆盖了多少页。
- **重新核对历史作品**：在更多菜单里，对已具备同步能力的连接再跑一遍对账。
- **撤销连接**：去掉这条平台连接。本机可能留下旧的登录目录，清理在「账号与设备」里单独确认。

同步必须由**保存登录态的那台主设备**上的保管人发起。客户端离线、连接被暂停、登录过期或平台要求验证时，进度会停在等待，并给出「重新核对平台登录」。

## 15. 本机 AI

业务页里的「服务器模型」管线上模型。客户端里的「本机 AI 配置」管这台电脑的模型。两套配置互不替代。

完整连接步骤、代理限制和故障表见 [USER_GUIDE.md](./USER_GUIDE.md)。这里只列使用顺序：

1. 所有者在「桌面 AI 策略」允许本工作区使用桌面 AI。若编辑者也要用自己的电脑，再打开「允许 editor 使用各自的桌面 AI 端点」。保存时按服务端要求重新输入密码。
2. 打开「客户端 → AI 连接设置…」。
3. 在「本机 AI 配置」填写配置名称、API 基础地址和模型名。地址只能是公网 HTTPS，或本机回环地址（例如 `http://127.0.0.1:1234/v1/`）。回环地址不表示提示词只留在本机：业务上下文仍先到线上 OPS，再经受限通道转到这台电脑上的模型。
4. API Key 可留空。密钥进当前 Windows 用户的系统加密存储，设置页只看到掩码，不写入线上模型配置。
5. 点「连接 WSS 通道」。这一步只验证账号、设备和通道，不调用模型。
6. 在「能力自检」里对选定模型启动自检。自检会真实调用模型，可能计费；它用合成输入，不读作品，也不执行业务工具。文本通过不代表 JSON、工具调用、识图或图片生成也通过。
7. 在「任务映射」里把每个任务设为「服务器」「此客户端」或「停用」。先存本机草稿，再把业务 AI 执行模式设为「此客户端 AI」并确认应用。应用会重新加载业务页，先保存未提交的编辑。默认任务必须有映射。向量检索只能在服务器执行。
8. 切回「服务器 AI」后，后续任务用工作区的线上模型。客户端 AI 不可用时不会自动改走服务器。

休眠或断网后通道会断开。恢复后要手动再点「连接 WSS 通道」。重新打开客户端时，如果这个账号仍是「此客户端 AI」，客户端会尝试恢复；失败则保持该模式并标明通道不可用。

「断开」只关通道，不撤销线上设备。设备在「账号与设备 → 本人已注册设备」里单独撤销。「清除此账号本机数据」删除当前账号在本机的模型密钥、设备私钥和映射草稿，并清掉当前业务站点的登录状态后退出；不删除线上作品，也不撤销线上设备。多个 OPS 账号要分别登录后清理。卸载可能留下用户目录中的应用数据。

公网模型可选直连、系统代理或手动 HTTP(S) 代理。回环模型始终直连。不支持 SOCKS，也不支持代理失败后自动改直连。图片生成若返回其他域名的图片，要把精确主机名写入「允许的图片 CDN 域名」。

诊断从「诊断与关于」导出。导出的文件去掉账号名、设备标识、模型地址、模型名、提示词和密钥。发送前仍要自己看一遍。

## 16. 使用时要守住的边界

这些是产品行为，不是隐藏开关：

- 不提供「全部起草」「全部确认」「全部入库」。选题、素材标签、复盘建议和 AI 卡片都是逐条确认。
- 智能体执行模式没有「全部执行」。写入由你逐张卡片执行。
- 内容日历和每日推荐都不自动发布。发布发生在公众号草稿箱或你自己的平台后台。
- 计划发布日、热点替换、运营方案槽位被采用，都不会批量生成作品。
- 本机 AI 失败、断线、设备被撤销或工作区收紧授权时，调用失败并提示。已经发出的请求不自动重放，也不自动改用服务器模型。
- 平台登录态、模型密钥和映射草稿在本机。作品、选题、档案和成员在线上工作区。清本机数据不影响线上内容。
- 观察者和系统管理员代入时，界面保持可查看，写入和平台读取按钮不可用，并说明原因。

## 17. 常见情况

| 现象 | 处理 |
| --- | --- |
| 打开后没有进入工作台 | 当前没有可选平台账号。从头像菜单打开账号选择器，或让所有者添加账号。 |
| 提示当前账号已停用 | 换一个启用中的账号，或在已停用列表里重新启用。停用账号不能创作和回填。 |
| 业务页提示线上服务不可达 | 检查网络后重新登录。客户端不用缓存页面代替线上业务。 |
| 此客户端 AI 不可用 | 看标题栏模式是否带「通道未就绪」，再到 AI 连接设置手动连接 WSS。不要指望它自动改走服务器。 |
| 能力自检有项失败 | 该项不要映射到这个模型。自检失败不会自动换另一个模型。 |
| 平台「同步」是灰的 | 读按钮下方的原因：策略未开、能力未验收、登录未核对、客户端离线，或不是保管人这台设备。 |
| 同步停在等待重新登录 | 在平台连接上点「重新核对平台登录」，完成验证后再继续。 |
| 退出被取消 | 作品还有内容没确认保存。回到作品页等保存完成后再退出。 |
| 设置改了一半关不掉 | 选择放弃修改，或先保存。保存进行中时会提示稍候。 |
| 要给支持人员看环境 | 从「诊断与关于」导出脱敏诊断，自己再检查一遍文件。 |
