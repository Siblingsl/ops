本机模型配置

只允许公网 HTTPS，或 localhost / 127.0.0.1 / ::1 回环地址。公网目标会在本机解析并固定 IP 后连接。

回环模型强制直连。系统代理仅使用系统解析出的首个规则，不会失败后静默直连；不支持 SOCKS、远端 DNS 目标解析或未经校验的代理。
