# 打工人重启阅读：每天10页的笨办法

- 平台：小红书
- 作品 ID：d0be8ed3-a397-4715-b25f-920024dd2b91
- 核心观点：重启阅读靠的是把门槛降到不可能失败，而不是买更多书。
- 模型：workbuddy-ai/hy4flash-free

## 先说结论

重启阅读，先别急着买书📌

先把目标缩到很小：每天10页。

不是买更多书，也不是给自己排很满。就是翻开手边那本，读10页。少一点，也算开了头。

打工人下班后已经够累了，阅读如果一开始就设得太用力，很容易断。

能做到，才是能继续的前提。先把门槛降到不好放弃，书才会慢慢回到日常里。

## 目标只设10页

下班后真的别跟意志力较劲📌

今天不要求自己状态很好，也不要求读很多。就翻开手边那本，读10页。读到了，就算完成；少一点，也算开了头。

阅读重启不是靠一时用力。打工人已经够累了，目标设得太满，很容易断。先把门槛放小到不好放弃，书才会更容易回到日常里。

## 把书塞进日常动作

别把阅读留给“有空再说”。把书塞进一个固定动作里：通勤路上、午休前、睡前，挑一个你每天都会发生的时间点📖

到点就翻书，不用重新做决定，也不用等状态来了。这样阅读就不是额外任务，而是顺手接进日常里。
