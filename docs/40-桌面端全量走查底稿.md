# 40 · 桌面端全量功能走查底稿（阶段一）

> 任务：桌面端全量功能走查 + 问题清单修复（两阶段）。本底稿是阶段一走查的执行清单；问题登记在 `docs/41-桌面端全量走查问题清单.md`（docs/36~39 编号已占用）。
> 范围：桌面端形态（Electron 主进程 `desktop/src/` + 桌面渲染器 `renderer/`）+ 共用 Go 后端 `server/`。
> 状态取值：`待走查` / `通过` / `问题N条` / `未验证（原因）`。每完成一个功能立即更新本文件并登记问题。

## 走查原则

- 每个功能点：正常流程 + 关键异常（断网/空数据/权限不足）+ 边界（超长/空列表/重复操作/快速连点）。
- 桌面 UI 用 Playwright 驱动真实 Electron 窗口逐步截图到 `.playwright-results/desktop-renderer/`（按 `F-xx-stepN.png` 命名），逐张检查错位/截断/空态。
- 后端协议直接按协议调用（HTTP API + 鉴权/工作区头、越权用例），复用 `server/cmd/ops-e2e` 模拟环境与既有 Go 测试。
- 红线专项：D-117 逐张执行、H-01~09 人工确认点、HC-26~31 智能体约束 —— 全部走查范围内。
- 不修改任何业务代码；只允许写问题登记文档、本底稿、新增测试脚本。
