> 所有影响设计的平台规则、接口能力和法规事实都登记在这里。设计文档引用时使用编号（F-xxx / V-xxx），禁止引用未登记的"事实"。

> 最后更新：2026-10-21

## 状态定义

| 状态 | 含义 |
| --- | --- |
| 已验证 | 有官方文档、官方公告或权威媒体报道的官方回应作为依据 |
| 待验证 | 有线索但缺少官方依据，或需要实测确认；不得作为设计前提 |
| 不可实现 | 官方明确不提供，或实现方式违反平台规则或法律 |

平台规则会变，每条事实都记录核验日期。阶段 8 开工前、每个版本上线前都要复核"已验证"事实。
