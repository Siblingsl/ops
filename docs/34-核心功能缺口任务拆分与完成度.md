## 0 怎么用这份文档

1. **一次只开一个小任务**（`CF-xx-yy` 或 `CF-P2-*-yy`），提交信息写该编号。
2. 开工前读本任务的「位置 / 方案 / 验收」三节，再读引用的设计段落。
3. 做完后**必须**更新本任务四态百分比 + 所属整项汇总表；同步在 `docs/08` 追加实施记录。
4. 百分比以**证据**为准：有定向测试退出码 / E2E 截图路径 / 人工样本记录才可上调「验」「交」；仅有代码不得把「交」抬过 0。
5. **核心缺口与 P2 增强分表计分**，互不并入对方加权总完成度。

### 0.1 完成度口径（强制）

每个小任务与每个整项都填四列百分比（整数 0–100）：

| 列 | 含义 | 上调条件 |
|---|---|---|
| **码%** | 设计契约在源码中的落地比例 | 文件存在且主路径可走通（mock 可） |
| **验%** | 自动化 + 登记过的定向验收 | 有命令、退出码、失败为 0 的记录 |
| **交%** | 用户可达且整项可关闭 | 默认部署可达（或已拍板的开关策略）+ `docs/08` 写明整项关闭 + 无「整项不关闭」 |
| **综合%** | `round(码×0.4 + 验×0.3 + 交×0.3)` | 公式固定，禁止手填「感觉分」 |

整项综合% = 其下**未取消**小任务综合%的算术平均（可按「权重」列加权；未标权重则等权）。

**禁止**：用 mock 成功把「交%」抬到 >0；用「页面能点」把「验%」抬到 100；删除/跳过测试抬分。

### 0.2 状态标签
