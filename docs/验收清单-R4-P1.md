## DEV-401 漫画文字工作流（FR-M8-01～04）

- [ ] 漫画账号下可维护角色设定卡（名、外貌、性格、口头禅、参考图），归属当前账号
- [ ] 新建漫画作品：填选题/观点后可生成分镜（指定格数如 4/6/9）
- [ ] 观点为空时不能生成分镜（H-02）
- [ ] 分镜未确认时不能批量起稿；确认后可逐格文案/对白/绘图提示词
- [ ] 绘图提示词含所引用角色外貌；可回传图片并按格序进入检查

## DEV-402 公众号 `newspic`（FR-M10-03）

- [ ] 漫画（或图集）作品检查通过后，可写入**图片消息草稿**（非长图文）
- [ ] mock 下推送成功；图片走永久素材；正文为纯文本转换
- [ ] 超过 20 张时有明确限制/提示（若 UI 暴露）

## DEV-403 配图建议与 3:4 裁剪（FR-M7-03、04）

- [ ] 正文段落可「配图建议」，得到描述 + 可复制提示词
- [ ] 素材/插图可按 **3:4** 裁剪并**另存为新资源**（原图不变）

## DEV-404 人工修改比例（FR-M4-07）

- [ ] 有 AI 初稿的段落经人工改写后，作品顶栏显示「人工修改比例约 xx%」
- [ ] 文案表明仅自查参考，不阻断流程

## DEV-405 AI 风格摘要（FR-M2-05）

- [ ] 账号档案：从风格样本生成摘要（流式）
- [ ] 可编辑后保存；再次打开为编辑后版本

## DEV-406 小红书分页 + 源稿更新（FR-M5-05、06）

- [ ] 小红书作品发布包页可生成分页文案（封面页 + 要点页）
- [ ] 公众号作品派生小红书后，再改源稿：衍生作品顶栏出现「源稿已更新」

## DEV-407 同质化 / 选题去重（FR-M3-04、FR-M9-06）

- [ ] 新建选题标题与历史高度相似时，入库前有提醒且**不阻止**入库
- [ ] 发布前检查出现 `similarity` 项，可「已知悉 / 已修改」；未确认不能推送/出包

## DEV-408 账号默认主题（FR-M6-05）

- [ ] 公众号档案排版页可设默认主题并保存
- [ ] 该账号下**新建**作品继承该主题

## DEV-409 导入平台导出（FR-M11-04）

- [ ] 复盘页可上传 CSV：预览匹配结果
- [ ] 无法自动匹配的行可人工指定作品后确认导入
- [ ] （可选）用实账导出再验一次 → 依赖 V-006 / V-011，本清单不强制

## DEV-410 草稿状态同步（FR-M10-06）

- [ ] 已推送公众号草稿的作品可「同步状态」
- [ ] mock 模拟草稿从草稿箱消失后：提示可能已发表，**作品状态不会被自动改为已发布**（HC-07）
- [ ] 标记已发布仍须人工回填

## DEV-411 口述 / 要点扩写（FR-M4-08）

- [ ] 作品编辑页可粘贴要点，流式整理成带小标题草稿
- [ ] 「写入正文」后大纲/段落块正确落库，可继续分段编辑

## DEV-412 素材快速收集（FR-M2-06）

- [ ] 任意页 `Ctrl+Shift+M`（或浮动按钮）打开收集
- [ ] 文字存入素材库，默认归属当前账号；可在素材库中看到

## DEV-413 广告法极限词（FR-M9-07）

- [ ] 正文含「最」「第一」等极限词时，检查出现 `ad_law` 项与替换建议
- [ ] 须逐项确认；未确认不能推送/出包（无「全部确认」）

## DEV-414 提示词模板 + 数据导出（FR-M12-05、06）

- [ ] 设置 → 提示词：可查看/编辑任务类型模板并保存
- [ ] 设置 → 导出：作品 / 素材 / 复盘可导出 CSV 或 Markdown 并成功下载
