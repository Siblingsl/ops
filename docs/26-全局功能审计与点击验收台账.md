# 26 全局功能审计与点击验收台账

> 版本：v0.1（2026-11-03）
> 背景：用户要求对每一个用户可感知功能逐项核查、逐项点击式验收，"好用/智能"须有可复现量化证据。本文档是本轮（登记 08 的 DEV-QA26）唯一的清单与验收台账，不与 22（动线问题）、25（上一轮全面测试）重复建账：发现的新动线问题仍记入 22，完成度结论回写 25/08/04。
> 方法：①基线（Git/vet/HC/双端 typecheck+单测+Go 全量）；②按旅程组逐页面点击走查（dev 栈真实界面 + Playwright 工具 + 截图/网络日志/数据库只读核验）；③发现问题走"复现→根因→最小修复→点击复验→回归→提交"闭环；④量化指标（效率/性能/稳定性/智能性）按固定样本实测。
> 边界：本地 mock 环境验证流程与契约；真实模型、真实平台、生产迁移、签名安装升级等保持 08 既有未验收记录，不在本文档内声称通过。

## 0. 状态字典

| 状态 | 含义 |
| --- | --- |
| 未检查 | 已建账，尚未走查 |
| 已检查-通过 | 点击走查完成，正常路径+至少一条关键异常通过 |
| 部分检查 | 已取得有效点击证据，但功能范围仍有未验路径；条目注明剩余项 |
| 已检查-有缺陷 | 走查发现缺陷，缺陷已记 §5 |
| 修复待复验 | 缺陷已修复，等待复跑原步骤 |
| 本地通过 | 已检查-通过 且 相关回归已跑 |
| 受阻 | 因环境/权限/外部依赖无法走查，原因记入条目 |
