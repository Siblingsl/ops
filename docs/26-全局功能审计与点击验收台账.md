# 26 全局功能审计与点击验收台账

> 版本：v0.1（2026-11-03）
> 背景：用户要求对每一个用户可感知功能逐项核查、逐项点击式验收，"好用/智能"须有可复现量化证据。本文档是本轮（登记 08 的 DEV-QA26）唯一的清单与验收台账，不与 22（动线问题）、25（上一轮全面测试）重复建账：发现的新动线问题仍记入 22，完成度结论回写 25/08/04。
> 方法：①基线（Git/vet/HC/双端 typecheck+单测+Go 全量）；②按旅程组逐页面点击走查（dev 栈真实界面 + Playwright 工具 + 截图/网络日志/数据库只读核验）；③发现问题走"复现→根因→最小修复→点击复验→回归→提交"闭环；④量化指标（效率/性能/稳定性/智能性）按固定样本实测。
> 边界：本地 mock 环境验证流程与契约；真实模型、真实平台、生产迁移、签名安装升级等保持 08 既有未验收记录，不在本文档内声称通过。

## 0. 状态字典

| 状态 | 含义 |
| --- | --- |
| 未检查 | 已建账，尚未走查 |
| 已检查-通过 | 点击走查完成，正常路径+至少一条关键异常通过 |
| 已检查-有缺陷 | 走查发现缺陷，缺陷已记 §5 |
| 修复待复验 | 缺陷已修复，等待复跑原步骤 |
| 本地通过 | 已检查-通过 且 相关回归已跑 |
| 受阻 | 因环境/权限/外部依赖无法走查，原因记入条目 |

## 4. 验收记录（按批次追加）

### 批次 A（G1+G2）与批次 C 前半（G4 主链），2026-11-03/04，1280×720，dev 栈（API :8080 + mock 模型 :8091）

**走查路径**：登录页 → 错误凭据（错误提示带请求 ID）→ 注册（短密码按钮禁用 → 强密码注册成功自动建工作区）→ /settings/accounts?new=1 添加平台账号对话框（四步引导 + 平台/类型联动）→ 建号跳档案向导（粘贴样本→AI 档案草稿，可跳过）→ 工作台首次状态（五步引导第 1 步已完成判定、主线空态、AI 用量 0、账号健康度 0/100 七项分解）→ 新建作品面板（标题可空/模板/选题联动/类型预览）→ 编辑器（观点 H-02 → AI 大纲 5 段 + 来源回执"定位档案、创作依据 1 项（有缺项）" + 确认 toast → 逐段起草 5/5 + [待核实] 占位 + lint 1 处提示 + 人工修改比例 0% → 标题候选 6 个带特征标签 + 本地规则预览 39/50）→ 提交检查确认闸门（1 待核实 + 5 敏感词提示，可选先处理）→ 检查页（格式 2/4：待核实标记被"必须修改"正确阻断、AI 事实核查异步进行中、逐项列表）。

**量化观察（单样本，非达标声明）**：注册→建号→首篇作品 5 段起草完成全链路约 4 分钟、必要点击约 25 次、页面切换 0（SPA 单页内滚动）；AI 大纲生成 5.0s 首反馈、逐段起草每段 0.5–0.7s（mock）；标题候选 1.2s；全程无控制台报错、无重复提交、自动保存无丢失。

**已验证边界**：无账号时主导航 fallback 到 /settings/accounts（合理引导）；无账号点击他人作品链接被服务端拒绝（404 提示带请求 ID）；短密码注册按钮禁用；错误凭据提示不泄露存在性以外的信息。

**发现缺陷**：2G-1（最近打开跨用户泄露，已修）、2G-2（候选卡 1280 视口竖排，已修）、2G-3（步骤计数伪影，撤销）——见 22 §2G 与 §5。

### 批次 B（G3 选题与运营），2026-11-04 00:00-00:45，同环境

**走查路径**：选题池（库存水位条 0/12 需补提示）→ 手动添加选题（0/80 计数、空标题禁用）→ 卡片菜单（编辑/置顶/放弃/核验/删除）→ 核验对话框（20-500 字下限：短说明禁用 ✓ → 核验成功 toast"60 天内可直接进入可排期"）→ 编辑选题卡设计划日（只存字段不进库存，hint"只用于提醒"已说明）→ 菜单"进入可排期"（预填日期 → 提交后库存 1/12、需补 11 ✓）→ 采用并开始写（新作品标题/计划日期/角度提示预填，H-02 观点仍由用户写 ✓）→ 回选题池：待定→已采用、库存回 0/12（建稿转 used ✓）、新增平均周转/本月采用率统计 → 体检（规则 35/55 部分覆盖 + AI 未完成不可用原因"定位标签缺失" + 依据/缺失明细全透明）→ 热点选题（H-01 声明、粘贴资讯 3.1s 生成候选带来源回执与合规理由、逐条入库→待定+1、已入库状态）→ 收件箱（记灵感→AI 建议归类（建议不自动转换）→整理对话框（预填标题/角度/读者）→转为选题→toast+直达按钮）→ 内容日历（排期选题出现在 11-05、未排期面板作品/选题分栏、不自动发布声明）→ 运营页（起号三步：问卷→3 方案对比（支柱占比合计 100%）→编辑启用→自动触发今日推荐异步 job（受理提示"可稍后查看"→约 90s 完成落卡）→推荐卡上下文真实利用支柱/计划、逐条采用走 H-01 内联确认→"已处理这条推荐"+已采用状态）。
