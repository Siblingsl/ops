# 30 渲染包上移方案（2026-11-09）

> 目标：把 `desktop/renderer-src/` 上移到仓库根 `renderer/`，与 `web/` 平级，去掉一层嵌套。
> 纪律：**纯位置迁移，不改业务逻辑、不改测试断言、不放宽任何守卫**；每步有门禁与回滚，任何一步不过就停。

---

## 1. 红线

1. **不合并依赖树**：`desktop` 与 `renderer-src` 的直接依赖只有 `typescript` 一项重叠，合并省不下空间，却要把 Node/CJS 与浏览器/ESM 两套编译目标塞进一个 `tsconfig`。本次只搬位置。
2. **不改任何 `*.test.*` / `*.spec.ts` 的断言与覆盖范围**。E2E 里的路径常量按新深度调整，守卫规则同步反转（原来是"必须是 `../../`"，现在是"必须是 `../`"），**不是放宽**。
3. **历史文档不改写**：`docs/08`、`26`、`27`、`90`、`17`、`22`、`25`、`24`、`28`、`acceptance/*` 里的旧路径是历史验收记录，保持原样；只在 `AGENTS.md`、`desktop/README.md`、`deploy/desktop-api-migration.md` 与 `docs/29` 顶部更新/加注。
4. 回滚点：`git tag pre-renderer-move-20261109`。

---

## 2. 目标结构

```
repo/
├─ desktop/            Electron 主进程 + 打包配置
│  ├─ src/             主进程 TS（→ .build/）
│  ├─ test/            主进程单测
│  ├─ scripts/         启动脚本
│  ├─ forge.config.cjs 打包配置
│  └─ renderer/        打包用渲染产物（构建生成，extraResource）
├─ renderer/           桌面业务界面源码项目（本方案新增位置）
│  ├─ package.json / pnpm-lock.yaml / pnpm-workspace.yaml
│  ├─ tsconfig.json / vite.config.ts / playwright.config.ts
│  ├─ App.tsx main.tsx components/ layout/ lib/ pages/ styles/
│  ├─ e2e/ tests/ scripts/
│  └─ dist/            非 desktop 模式的构建产物（ignore）
├─ web/                Web 前端项目（不变）
└─ server/ ...
```

层级：`desktop/renderer-src/pages/work/editor-state.tsx`（6 层）→ `renderer/pages/work/editor-state.tsx`（5 层）。

**命名说明**：根 `renderer/` 是**源码项目**，`desktop/renderer/` 是**构建产物**（已 ignore）。两者不会冲突，但容易看混，`AGENTS.md` 里已用一句话点明。

## 3. 影响面清单（逐项）

### 3.1 目录移动

```bash
git mv desktop/renderer-src renderer
```

移动前先把 `desktop/renderer-src/node_modules` **移到隔离区**：pnpm 的 `node_modules/*` 是**绝对符号链接**（实测 `node_modules/react -> /f/code/project/OPS/desktop/renderer-src/node_modules/.pnpm/...`），整体 rename 后全部失效。移动后在新位置执行一次 `pnpm install --frozen-lockfile`，等价于 CI 的全新安装。

### 3.2 构建与工具链（2 处，最危险）

| 文件 | 现在 | 改为 | 说明 |
|---|---|---|---|
| `renderer/vite.config.ts` | `outDir: '../renderer'` | `'../desktop/renderer'` | **不改成这样，`vite build` 会清空源码目录本身**（新位置下 `../renderer` 就是自己） |
| `renderer/vite.config.ts` | `require('../.build/proxy.js')` | `require('../desktop/.build/proxy.js')` | 只在 `OPS_API_PROXY` + https 目标时触发，常规构建不报错；由 `desktop/test/vite-proxy.test.cjs` 覆盖 |

### 3.3 运行时脚本与打包配置

| 文件 | 改动 |
|---|---|
| `desktop/package.json` | 3 个脚本 `--dir renderer-src` → `--dir ../renderer`（`build:renderer`、`test:renderer`、`test:e2e:renderer`） |
| `desktop/scripts/start.cjs` | `rendererRoot = join(desktopRoot, 'renderer-src')` → `join(resolve(desktopRoot,'..'), 'renderer')`；错误提示文案同步 |
| `desktop/forge.config.cjs` | `ignore` 正则去掉已不存在的 `renderer-src`；`extraResource: ['renderer']` 不变 |

### 3.4 测试与守卫

| 文件 | 改动 |
|---|---|
| `renderer/e2e/*.ts`（27 个）+ `playwright.config.ts` | 全部 `../../` → `../`（98 处：`output` 41、`.playwright-results` 34、`docs` 9、`testdata` 4、`tmpverify` 1、`server` 1、`../..` 3）。规则统一：项目整体上移一层，cwd 相对与 `__dirname` 相对都要少一级 |
| `renderer/tests/e2e-boundary.test.mjs` | **单独重写**：原规则"仓库根引用必须 `../../`"反转为 `../`；`WRONG_DEPTH` 改为拦 `../../`（越界到仓库外）；桌面级依赖白名单由 `../node_modules|.build` 改为 `../desktop/`；测试名与注释同步 |
| `renderer/tests/*.test.mjs`（3 个） | `../../../server` → `../../server`、`../../testdata` → `../testdata`（同一条"少一级"规则） |
| `renderer/scripts/probe-*.mjs`（2 个） | `../../.playwright-results` → `../.playwright-results`；用法注释 `cd desktop/renderer-src` → `cd renderer` |
| `desktop/test/vite-proxy.test.cjs` | `rendererRoot = resolve(__dirname, '../renderer-src')` → `'../../renderer'` |
| `desktop/test/browser-bridge.chrome.e2e.cjs` | `require('../renderer-src/node_modules/@playwright/test')` → `'../../renderer/node_modules/...'` |
| `scripts/check-e2e-pairs.mjs` | `DESKTOP_E2E` → `join(repoRoot,'renderer','e2e')`；注释同步 |
| `web/tests/web-e2e-boundary.test.mjs` | 正则 `desktop\/renderer-src\/(src|e2e)` → `renderer\/(src\|e2e)` 的新形态（防 Web 用例引用桌面实现） |
| `web/e2e/support.ts`、`web/e2e/README.md`、`web/e2e/*.spec.ts`（4 处） | 注释里的桌面路径 |

### 3.5 CI

`.github/workflows/ci.yml` 5 处：

- `cache-dependency-path: desktop/renderer-src/pnpm-lock.yaml` → `renderer/pnpm-lock.yaml`
- `working-directory: desktop/renderer-src` → `renderer`
- `pnpm --dir renderer-src run typecheck|test:unit` → `--dir ../renderer`
- e2e job：`pnpm --dir ../desktop/renderer-src install` → `--dir ../renderer`
