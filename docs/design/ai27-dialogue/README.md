## 入口与状态含义

- **记忆**：添加菜单的「跨对话记忆」入口；候选须本人确认后才长期保存。图中菜单不是已经写入记忆的回执。
- **插件与 MCP**：从添加菜单选择连接；连接/发现工具不自动批准写操作。
- **子 agent**：从添加菜单进入并行研究；图中没有自动启动子 agent，也没有增加并行批量写入按钮。
- **语音**：输入台常驻「语音 ▾」，添加菜单同时保留语音入口；同一入口下提供实时双向通话与可编辑转写两种流程。正式界面需另做录音、权限、通话结束与转写编辑状态。
- **桌面应用**：每次由用户选择目标应用；此图没有授权全桌面持续访问。
- **浏览器**：从添加菜单的 Chrome 标签项，或右上方工作视图进入浏览器页签；具体 profile、标签与 AI 会话明确区分，不在输入栏继续堆叠常驻按钮。
- **工作视图**：任务、上下文、产物、浏览器同时只显示一个主内容。点来源、产物或任务应打开对应页签。
- **业务卡片**：仅当前单张有「执行／拒绝」，等待确认使用琥珀文字，不以一轮对话完成代替业务完成。

## Chrome 技术待证边界

第二图只展示当前可依据机制设计的 **Google Chrome 外部标签连接路径**：页面实际运行和操作在 Chrome 自己的窗口中，OPS 右侧是目标标签、证据快照与控制状态，不是完整 Chrome 的原生内嵌窗口；证据图不接受伪装成网页原生交互的点击。

「应用内·待验证」只保留布局位置。用户要求的**完整 Google Chrome 内置与 AI 操作能力**仍须按照 27 第 6 节独立技术验证；本图及外部 Chrome 连接不能替代最终内置验收，不能把 Electron/Chromium 视图更名为完整 Chrome 来满足要求。

图中浏览器截图框内部的网页也是原创矢量示例，无真实浏览器截图取证之意；所有运行、读取、更新和任务进度均为拟议状态示例。

## 本次检视与未验证范围

本次使用本机 Chrome 的独立临时无头会话打开本地 SVG 并导出 PNG；没有启动 OPS 产品服务、读取个人 Chrome profile 或连接第三方网站。已逐张检视 PNG：中文可读，轨道/列表/输入台和分栏一致，操作卡与报告不重叠，Chrome 路径说明和接管/停止入口可见。修正了初稿的状态文字露边、研究页面数量不一致，并去掉无业务含义的装饰文案。

静态稿不验证实际点击、键盘焦点、读屏、IME、DPI、窄窗、深色主题、Windows 原生视图层级、外部 Chrome 控制、语音、MCP 或模型质量。开发时仍需依 27 的交互/权限/异常与验收条目逐项补齐；三张稿不作为“全部状态已设计”的证明。
