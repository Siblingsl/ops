# D-131 三平台本机登录首轮验收

日期：2026-10-21

本轮完成了业务账号详情页到本机设置的受限入口、目标账号定位、分步登录对话框和专用 Chrome／Edge 登录窗口。小红书与公众号可继续身份核对和服务端连接；头条仅能本人打开官方登录页，稳定身份及服务端身份能力未验证前，流程明确保持“待验证”，不建立数据连接或开启读取。

本机验证结果：

- `desktop` TypeScript 构建通过，`web` TypeScript 检查通过。
- 桌面完整 Node 测试集 152/152 通过，其中覆盖登录／IPC／profile／UI intent／身份策略。
- Playwright 使用模拟 IPC 操作了目标账号定位、浏览器选择、本人请求核对、身份确认和完成态。900×650、设置窗最小 760×640、390×740 下弹窗均保持在视口内，底部主按钮可见，没有横向溢出；截图保存在 `output/platform-login-design/login-ui-desktop.png` 与 `login-ui-narrow.png`。
- Web 账号详情 Playwright E2E 通过：普通 Web 不显示本机登录按钮；模拟桌面呈现后头条卡显示入口并生成对应账号的固定 UI intent。检查 960×640 按钮边界与页面宽度无溢出，截图保存在 Web 的 `test-results/d131-platform-login-entry-*/d131-toutiao-login-entry.png`。
- 本机实际签名 Chrome 155 和 Edge 155 分别启动小红书、公众号、头条官方首屏，窗口均保持打开。公众号主页及扫码认证子页已按实测路径加入窄范围导航白名单。

实测没有输入凭据、扫码、读取平台身份或建立真实连接。Playwright 使用模拟本机 IPC；官方首屏启动仅证明当前开发机两款浏览器可启动并导航，不代表 Windows 打包版、正式账号权限、长期会话或风控安全已通过。

仍需正式验收：本人真实账号扫码与身份／服务端连接闭环；Windows 打包版 Chrome／Edge 有无组合；DPI／系统缩放与多屏焦点；平台会话有效期和更新后复用。头条还需先取得可核验的稳定创作者身份及服务端身份能力，之前不做连接和自动读取。对应计划仍见 20 文档 §20.9 的 IL-T01～IL-T18。
